## Validation Requirements

- E10 geometry reproduced with fidelity to Brand Lock v1.0 (Approved)  
- No geometry change, refinement, or alternate mark selection  
- Naming matches `ASSET-MANIFEST.md`  
- Release contains only production assets  
- Work remains historical and separate  
- App Icon sizes / margins follow Guide once written  
- Day / Night (or mono-light / mono-dark) variants remain legible  
- No checklist, loop, smile, mountain, or productivity metaphors introduced  

---

## Out of Scope

- New brand concepts or metaphor exploration  
- Revisiting Breath A / C / J as primary mark  
- Widget / Watch implementation  
- App code integration (unless a later explicit task)  
- ROADMAP / CHANGELOG updates in architecture-only tasks  
- Placeholder binary “dummy” assets
