# Brand Architecture Decision Records

## Purpose

This directory records brand and product-experience architecture decisions introduced with Brand Foundation.

These ADRs preserve approved brand meaning. They do not redefine system architecture ownership.

## Audience

Architecture reviewers, product contributors, and agents applying Brand Foundation across surfaces.
